# Adjust: new features and APIs

A selection of features and APIs that I documented, named, or helped shape throughout development. These
features launched between 2016 and 2018 and the effort took place as part of an international product team.

## Audience Builder

![The Audience Builder feature and documentation](/img/adjust-new-features/audience-builder.png)

The Adjust Audience Builder was a first-of-its-kind feature that allowed marketers to create custom user lists 
for targeted advertising. I was heavily involved in feature development, including naming, UX copy, feature 
feedback and documentation.

## Ad spend API

![The ad spend API reference](/img/adjust-new-features/ad-spend-api.png)

The Adjust ad spend API was the first time ad networks could share granular information on the cost of specific 
ads and subsequent user actions through a third-party platform. I was involved in naming, feature feedback and 
documentation, in this case both user (dashboard) and developer (API integration) facing.

## Uninstall and reinstall tracking

![The uninstall and reinstall tracking documentation](/img/adjust-new-features/uninstall-reinstall.png)

Adjust was the first attribution company to offer uninstall tracking. I was heavily involved throughout 
feature development, including naming, documentation and feedback.

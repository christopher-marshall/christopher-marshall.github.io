# christopher-marshall.github.io

Portfolio site for Christopher Marshall, built with [Docusaurus](https://docusaurus.io/).

- The homepage is `src/pages/index.js`.
- Project write-ups live in `docs/projects/`. Each new page appears in the Projects sidebar automatically.

## Local development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

## Deployment

```bash
GIT_USER=christopher-marshall npm run deploy
```

This builds the site and pushes it to the `gh-pages` branch.
